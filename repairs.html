01

Next.js #85416 — request-body race

Broken: a timing-dependent request-body race could leave a downstream Server Action with incomplete JSON.

Impact: production-style requests could fail even though the same path sometimes appeared healthy.

Result: repaired independently and stress-verified: 15/15 final requests successful, a 7.2 MB slow-streamed request returned 200, and static checks were clean.

Public context: original issue #85416. Next.js had already merged its own upstream correction in PR #85418; this case demonstrates independent diagnosis and verification rather than claiming the upstream fix.

02

Google Gson — historical Java test failure

Broken: a historical allocator-instantiation test contained assertion behaviour rejected by modern checking.

Impact: the old test state no longer behaved cleanly in the reconstructed environment.

Result: focused repair completed and the target test passed. The resulting repair pattern aligned with the later upstream implementation.
03

Sonar CXX — executable-line mismatch

Broken: a historical test expected 23 executable lines while the implementation produced 55.

Impact: a genuine failing test in an older Java/Maven codebase, complicated by legacy runtime dependencies.

Result: the defect was repaired and the target test passed. The result matched the upstream behaviour.
04

SymPy — subclass behaviour lost

Broken: operations on a Permutation subclass returned the base type, losing the subclass across inversion, exponentiation and multiplication.

Impact: code relying on subclass behaviour could silently receive the wrong object type.

Result: required subclass behaviour restored. Focused and wider checks passed apart from known pre-existing failures.
